# Inputs

| Placeholder | Required | Description | Default |
|---|---|---|---|
| `EXTENSION NAME` → "myextension" | Yes | Extension identifier (e.g., "mytool") | — |
| `SKILL NAME` → "myextension" | Yes | Must match the folder name in skills/ at the package root | — |
| `COMMAND NAME` → "my-command.md" | Yes | Command file name in commands/ at the package root | — |
| `PACKAGE NAME` → "opencode-myextension" | Yes | npm package name; also the manifest file base | — |

**Load-bearing — do not simplify:** the deployment plan is content-based (ADR-0008): the content declaration (`"content"` in package.json, `"assets"` or `"code"`) decides the install modes — assets-only packages copy-install by default with `--mode plugin` as the opt-in, code-backed packages always plugin-register and `--mode copy` throws `CopyModeUnsupportedError`; copy install touches no config file at all — no permission blocks, no MCP entries, no `plugins` array edits; the `plugins` array is edited only by the surgical `PluginConfigEditor` (text splice, every other byte untouched, never a parse-then-reserialize, never rewrite config from `{}`, existing entry is a zero-write no-op); manifest-gated idempotency (never `.version` markers), the plugin-mode zero-write no-op includes a present entry (version match alone is not enough), and payload idempotency requires a recorded, hash-matching payload — a plugin-mode manifest with an empty file map means the load-time hook has not ensured assets yet, so the ensure path runs and records the payload hashes while preserving the recorded mode, entry, and target config file; config reading consults both `opencode.json` and `opencode.jsonc` per base, with `.jsonc` parsed leniently and `.json` strict, and every unparseable candidate is warned about; counts a path-form entry — a `file://` URL or filesystem path, string or `{ package }` object form — as registered when it resolves to this package via `EntryPredicate` (src/entry-predicate.ts, the one entry classifier shared with the suite), so `install` never adds a duplicate `name@latest` entry beside a live path entry; bundled content directories sit at the package root (`skills/`, `commands/`, `agents/` — no `assets/` intermediary) and resolve through `ASSET_LAYOUT_DIR`, which is `"."` by default; only when adapting a legacy package that wraps them in `assets/` is the constant overridden to `"assets"`, and a missing or empty asset source is a hard error naming the path, package name+version, cache dir, and install command — never a silent skip, and a manifest is never written when zero files were written; the manifest hashes the whole payload relative to the config base (skills and commands), and `migrateRootConfig` deletes nothing without a consent callback and is never called from `install()`. Cache hygiene is self-scoped (ADR-0007): every install — including a no-op — prunes this package's own cache copies (`<package>`, `<package>@latest`, `<package>@<version>`) from OpenCode's package cache (`$XDG_CACHE_HOME/opencode/npm`, falling back to `~/.cache/opencode/npm`), best-effort warn-and-continue, never touching other packages' cache dirs or pinned versions, and the load-time hook never prunes — only the CLI's install and `clear-cache` paths do. Every function here is scope-parameterized: the exact same logic serves the local scope base (`<project>/.opencode/`) and the global scope base (`~/.config/opencode/` or `$XDG_CONFIG_HOME/opencode/`), so a global install and a project install differ only in the base path — never in behavior. `status()` resolves the effective load per scope — the registration's config file, the raw entry as written, and the resolved source on disk (an npm spec against the package-cache key `<name>@<spec>` with the version read from the cached copy's `package.json`, newest generation first and mtime carried as a staleness hint; a path entry through `PluginEntryResolver.packageRoot`) — closing with an effective verdict plus warnings for a double-scope registration, a manifest/resolved version mismatch, a missing or incomplete cached copy, and `--online` registry staleness with warn-and-continue on an injectable fetch; status is read-only.

---

const SKILL_NAME = "myextension";
const COMMAND_NAME = "my-command.md";
const PLUGIN_NAME = "opencode-myextension";
const ASSET_LAYOUT_DIR = ".";

const normalizer = new PluginNameNormalizer();
const editor = new PluginConfigEditor();

export class CopyModeUnsupportedError extends Error {
  constructor() {
    super(
      `${PLUGIN_NAME} is code-backed (agents, tools, or plugin integrations) and cannot be installed in copy mode. ` +
        `Code-backed packages register as a plugin: run without --mode, or with --mode plugin.`
    );
  }
}

class AssetSourceMissingError extends Error {
  constructor(missingPath: string, cacheDir: string) {
    super(
      `Bundled asset directory missing or empty: ${missingPath}. ` +
        `The ${PLUGIN_NAME} package cache at ${cacheDir} is partial. ` +
        `Clear that directory and reinstall with: bunx ${PLUGIN_NAME} install --scope global`
    );
  }
}

export async function getPackageVersion(): Promise<string> {
  const content = await Bun.file(`${import.meta.dirname}/../package.json`).text();
  return JSON.parse(content).version;
}

export async function getPackageName(): Promise<string> {
  const content = await Bun.file(`${import.meta.dirname}/../package.json`).text();
  return JSON.parse(content).name;
}

export async function getContentDeclaration(): Promise<"assets" | "code"> {
  const content = await Bun.file(`${import.meta.dirname}/../package.json`).text();
  return JSON.parse(content).content === "code" ? "code" : "assets";
}

export async function resolveMode(requested: InstallMode | undefined): Promise<InstallMode> {
  if ((await getContentDeclaration()) === "code") {
    if (requested === "copy") throw new CopyModeUnsupportedError();
    return "plugin";
  }
  return requested ?? "copy";
}

function getPackageDir(): string {
  return join(import.meta.dirname, "..");
}

export function packageCacheRoot(): string {
  const xdgCacheHome = process.env.XDG_CACHE_HOME;
  if (xdgCacheHome) return join(xdgCacheHome, "opencode", "npm");
  return join(homedir(), ".cache", "opencode", "npm");
}

interface CacheOutcome {
  removed: string[];
  warnings: string[];
}

async function removeCacheTargets(packagesRoot: string, wanted: (name: string) => boolean): Promise<CacheOutcome> {
  const removed: string[] = [];
  const warnings: string[] = [];
  let entries: string[];
  try {
    entries = await readdir(packagesRoot);
  } catch (error) {
    if ((error as NodeJS.ErrnoException)?.code === "ENOENT") return { removed, warnings };
    throw error;
  }
  const targets = entries
    .filter(wanted)
    .sort()
    .map((name) => join(packagesRoot, name));
  for (const target of targets) {
    try {
      await rm(target, { recursive: true });
      removed.push(target);
    } catch (error) {
      const message = error instanceof Error ? error.message : String(error);
      warnings.push(`Could not clear cached package ${target}: ${message}`);
    }
  }
  return { removed, warnings };
}

export async function prunePackageCache(): Promise<CacheOutcome> {
  const version = await getPackageVersion();
  const wanted = [PLUGIN_NAME, `${PLUGIN_NAME}@latest`, `${PLUGIN_NAME}@${version}`];
  return removeCacheTargets(packageCacheRoot(), (name) => wanted.includes(name));
}

export async function clearPackageCache(): Promise<CacheOutcome> {
  const prefix = `${PLUGIN_NAME}@`;
  return removeCacheTargets(packageCacheRoot(), (name) => name === PLUGIN_NAME || name.startsWith(prefix));
}

export function getGlobalConfigPath(): string {
  const xdgConfig = process.env.XDG_CONFIG_HOME;
  if (xdgConfig) {
    return join(xdgConfig, "opencode");
  }
  return join(homedir(), ".config", "opencode");
}

export function getLocalConfigPath(projectDir: string): string {
  return join(projectDir, ".opencode");
}

function scopeBase(scope: Scope, projectDir: string): string {
  return scope === "global" ? getGlobalConfigPath() : getLocalConfigPath(projectDir);
}

async function copyDir(src: string, dest: string, skip: Set<string> = new Set()): Promise<number> {
  await mkdir(dest, { recursive: true });
  if (skip.has(dest)) return 0;
  let written = 0;
  for (const entry of await readdir(src, { withFileTypes: true })) {
    const s = join(src, entry.name);
    const d = join(dest, entry.name);
    if (skip.has(d)) continue;
    if (entry.isDirectory()) {
      written += await copyDir(s, d, skip);
    } else {
      await Bun.write(d, Bun.file(s));
      written++;
    }
  }
  return written;
}

async function requireAssetDir(path: string): Promise<string> {
  if (!(await exists(path))) throw new AssetSourceMissingError(path, getPackageDir());
  const contents = await readdir(path);
  if (contents.length === 0) throw new AssetSourceMissingError(path, getPackageDir());
  return path;
}

async function payloadPaths(configBase: string): Promise<{ skillPath: string; commandPath: string }> {
  return {
    skillPath: join(configBase, "skills", SKILL_NAME),
    commandPath: join(configBase, "commands", COMMAND_NAME),
  };
}

async function ensurePayload(scope: Scope, projectDir: string, force: boolean): Promise<{ upToDate: boolean; skippedModified: string[] }> {
  const version = await getPackageVersion();
  const configBase = scopeBase(scope, projectDir);
  const { skillPath } = await payloadPaths(configBase);
  const manifest = new InstallManifest(configBase, PLUGIN_NAME);
  const existing = await manifest.read();
  const payloadRecorded = existing !== null && Object.keys(existing.files).length > 0;
  if (payloadRecorded && (await manifest.isUpToDate(version, configBase))) {
    return { upToDate: true, skippedModified: [] };
  }
  const skippedModified: string[] = [];
  const modified = await manifest.findConsumerModified(configBase);
  if (!force && modified.length > 0) {
    for (const file of modified) {
      console.warn(`Warning: skipping consumer-modified file ${file} (use --force to overwrite).`);
    }
    skippedModified.push(...modified);
  }
  const packagedSkillDir = await requireAssetDir(join(getPackageDir(), ASSET_LAYOUT_DIR, "skills", SKILL_NAME));
  const written = await copyDir(packagedSkillDir, skillPath, new Set(skippedModified));
  if (written === 0 && skippedModified.length === 0) throw new AssetSourceMissingError(packagedSkillDir, getPackageDir());
  const { commandPath } = await payloadPaths(configBase);
  const commandSource = await requireAssetDir(join(getPackageDir(), ASSET_LAYOUT_DIR, "commands"));
  await mkdir(join(configBase, "commands"), { recursive: true });
  await Bun.write(commandPath, Bun.file(join(commandSource, COMMAND_NAME)));
  const skipped = new Set(skippedModified);
  const hashes: Record<string, string> = {};
  for (const file of [...(await listFilesRecursive(skillPath)), commandPath]) {
    const rel = relative(configBase, file).replaceAll("\\", "/");
    const packagedCounterpart = file.startsWith(skillPath)
      ? join(packagedSkillDir, relative(skillPath, file))
      : join(commandSource, COMMAND_NAME);
    hashes[rel] = await sha256(skipped.has(file) ? packagedCounterpart : file);
  }
  await manifest.write({
    version,
    mode: existing?.mode ?? "copy",
    entry: existing?.entry ?? null,
    entryConfigPath: existing?.entryConfigPath ?? null,
    rootDir: null,
    files: null,
    hashes,
  });
  return { upToDate: false, skippedModified };
}

export async function ensureAssets(scope: Scope, projectDir: string, force: boolean): Promise<void> {
  await ensurePayload(scope, projectDir, force);
}

async function registerPlugin(scope: Scope, projectDir: string): Promise<{ upToDate: boolean; entry: string | null; entryConfigPath: string | null }> {
  const version = await getPackageVersion();
  const configBase = scopeBase(scope, projectDir);
  const entry = normalizer.normalize(PLUGIN_NAME) ?? PLUGIN_NAME;
  const manifest = new InstallManifest(configBase, PLUGIN_NAME);
  const existing = await manifest.read();
  const entryPresent = existing?.mode === "plugin" && existing.entryConfigPath
    ? (await editor.findRegistration(PLUGIN_NAME, { scope, projectDir })) !== null
    : false;
  if (existing?.version === version && entryPresent) {
    return { upToDate: true, entry: existing.entry, entryConfigPath: existing.entryConfigPath };
  }
  const outcome = await editor.ensurePluginEntry(PLUGIN_NAME, { scope, projectDir });
  if (outcome.action === "blocked" && outcome.warning) {
    console.warn(`Warning: ${outcome.warning}`);
    return { upToDate: false, entry: null, entryConfigPath: null };
  }
  if (outcome.action !== "noop" && outcome.action !== "updated" && outcome.action !== "created") {
    return { upToDate: false, entry: null, entryConfigPath: null };
  }
  await manifest.write({
    version,
    mode: "plugin",
    entry,
    entryConfigPath: outcome.configPath,
    rootDir: null,
    files: null,
    hashes: existing?.files ?? null,
  });
  return { upToDate: false, entry, entryConfigPath: outcome.configPath };
}

export async function checkMigrationNeeded(projectDir: string): Promise<{
  needed: boolean;
  rootConfigPath: string;
  dotOpenencodeConfigPath: string;
  rootConfig: Record<string, unknown> | null;
  dotOpenencodeConfig: Record<string, unknown> | null;
}> {
  const rootConfigPath = join(projectDir, "opencode.json");
  const dotOpenencodeConfigPath = join(projectDir, ".opencode", "opencode.json");
  const rootExists = await exists(rootConfigPath);
  const dotOpenencodeExists = await exists(dotOpenencodeConfigPath);
  if (!rootExists) return { needed: false, rootConfigPath, dotOpenencodeConfigPath, rootConfig: null, dotOpenencodeConfig: null };
  const rootConfig = await readJsonConfig(rootConfigPath);
  const dotOpenencodeConfig = dotOpenencodeExists ? await readJsonConfig(dotOpenencodeConfigPath) : null;
  return { needed: true, rootConfigPath, dotOpenencodeConfigPath, rootConfig, dotOpenencodeConfig };
}

export async function migrateRootConfig(
  projectDir: string,
  onConsent: (root: Record<string, unknown>, dot: Record<string, unknown> | null) => Promise<boolean>
): Promise<boolean> {
  const { needed, rootConfigPath, dotOpenencodeConfigPath, rootConfig, dotOpenencodeConfig } = await checkMigrationNeeded(projectDir);
  if (!needed || rootConfig === null) return false;
  if (!(await onConsent(rootConfig, dotOpenencodeConfig))) return false;
  if (dotOpenencodeConfig !== null) {
    const merged = { ...rootConfig, ...dotOpenencodeConfig };
    await writeJsonConfig(dotOpenencodeConfigPath, merged);
  } else {
    await mkdir(join(projectDir, ".opencode"), { recursive: true });
    await writeJsonConfig(dotOpenencodeConfigPath, rootConfig);
  }
  await rm(rootConfigPath);
  return true;
}

export async function install(
  scope: Scope,
  projectDir: string = process.cwd(),
  options: InstallOptions = {}
): Promise<InstallResult> {
  const { mode: requested, force = false } = options;
  const cache = await prunePackageCache();
  for (const warning of cache.warnings) {
    console.warn(`Warning: ${warning}`);
  }
  const mode = await resolveMode(requested);
  const configBase = scopeBase(scope, projectDir);
  const { skillPath, commandPath } = await payloadPaths(configBase);
  if (mode === "copy") {
    const { upToDate, skippedModified } = await ensurePayload(scope, projectDir, force);
    return { scope, mode, skillPath, commandPath, entry: null, entryConfigPath: null, skippedModified, upToDate, clearedCache: cache.removed };
  }
  const { upToDate, entry, entryConfigPath } = await registerPlugin(scope, projectDir);
  return { scope, mode, skillPath, commandPath, entry, entryConfigPath, skippedModified: [], upToDate, clearedCache: cache.removed };
}

export async function uninstall(scope: Scope, projectDir: string = process.cwd()): Promise<UninstallResult> {
  const configBase = scopeBase(scope, projectDir);
  const { skillPath, commandPath } = await payloadPaths(configBase);
  const manifest = new InstallManifest(configBase, PLUGIN_NAME);
  const manifestData = await manifest.read();
  const removed: string[] = [];
  let pluginRemoved = false;
  if (manifestData?.mode === "plugin") {
    const outcome = await editor.removePluginEntry(PLUGIN_NAME, { scope, projectDir });
    if (outcome.action === "blocked" && outcome.warning) console.warn(`Warning: ${outcome.warning}`);
    pluginRemoved = outcome.action === "removed";
  }
  if (await exists(skillPath)) { await rm(skillPath, { recursive: true }); removed.push(skillPath); }
  if (await exists(commandPath)) { await rm(commandPath); removed.push(commandPath); }
  if (manifestData !== null) { await rm(join(configBase, `${PLUGIN_NAME}.manifest.json`)); removed.push(join(configBase, `${PLUGIN_NAME}.manifest.json`)); }
  const skillsDir = join(configBase, "skills");
  const commandsDir = join(configBase, "commands");
  try { const skillsContents = await readdir(skillsDir); if (skillsContents.length === 0) await rm(skillsDir, { recursive: true }); } catch {}
  try { const commandsContents = await readdir(commandsDir); if (commandsContents.length === 0) await rm(commandsDir, { recursive: true }); } catch {}
  return { scope, mode: manifestData?.mode ?? null, removed, pluginRemoved };
}

export async function status(projectDir: string = process.cwd(), online: boolean = false, fetchFn: typeof fetch = fetch): Promise<StatusResult> {
  const detector = new RegistrationDetector(PLUGIN_NAME);
  const inventory = await detector.inventory(projectDir);
  let local = await scopeStatus("local", projectDir, inventory.local);
  let global = await scopeStatus("global", projectDir, inventory.global);
  const warnings: string[] = [];
  if (local !== null && global !== null && local.registered && global.registered) {
    warnings.push(`registered in both scopes (double-load risk): ${local.entryConfigPath} and ${global.entryConfigPath}`);
  }
  let effective: EffectiveStatus;
  if (online) {
    const outcome = await applyOnline([local, global], fetchFn);
    warnings.push(...outcome.warnings);
    local = outcome.scopes[0] ?? null;
    global = outcome.scopes[1] ?? null;
  }
  effective = effectiveStatus(local, global);
  return { local, global, effective, warnings };
}

async function scopeStatus(scope: Scope, projectDir: string, entries: RawConfigEntries[]): Promise<ScopeStatus | null> {
  const configBase = scopeBase(scope, projectDir);
  const manifest = new InstallManifest(configBase, PLUGIN_NAME);
  const manifestData: ManifestData | null = await manifest.read();
  const matched = await findMatchedRegistration(entries);
  if (manifestData === null && matched === null) return null;
  const classified = matched?.classified ?? null;
  const warnings: string[] = [];
  let resolvedVersion: string | null = null;
  let resolvedSource: "cache" | "checkout" | null = null;
  let resolvedModifiedMs: number | null = null;
  let resolvedName: string | null = null;
  if (matched !== null && classified !== null) {
    const outcome = await resolveEntrySource(classified.spec, dirname(matched.configPath));
    if (outcome.resolved !== null) {
      resolvedVersion = outcome.resolved.version;
      resolvedSource = outcome.resolved.source;
      resolvedModifiedMs = outcome.resolved.modifiedMs;
      resolvedName = outcome.resolved.name;
    } else if (outcome.status === "missing") {
      warnings.push(`${scope}: no cached copy for ${classified.spec}`);
    } else {
      warnings.push(`${scope}: cached copy for ${classified.spec} is incomplete`);
    }
    if (manifestData !== null && manifestData.version !== null && resolvedVersion !== null && manifestData.version !== resolvedVersion) {
      warnings.push(`${scope}: manifest records ${manifestData.version} but the resolved copy is ${resolvedVersion}`);
    }
  }
  return {
    scope,
    installed: true,
    version: manifestData?.version ?? null,
    mode: manifestData?.mode ?? (matched !== null ? "plugin" : null),
    entry: classified !== null ? classified.spec : manifestData?.entry ?? null,
    entryName: classified?.name ?? null,
    entryVersion: classified?.version ?? null,
    entryConfigPath: matched !== null ? matched.configPath : manifestData?.entryConfigPath ?? null,
    pluginInConfig: matched !== null,
    resolvedVersion,
    resolvedSource,
    resolvedModifiedMs: resolvedModifiedMs,
    resolvedName,
    publishedVersion: null,
    registered: matched !== null,
    warnings,
  };
}

async function findMatchedRegistration(entries: RawConfigEntries[]): Promise<MatchedRegistration | null> {
  for (const candidate of entries) {
    for (const raw of candidate.rawEntries) {
      const classified = await EntryPredicate.matched(raw, PLUGIN_NAME, dirname(candidate.configPath));
      if (classified !== null) return { configPath: candidate.configPath, classified };
    }
  }
  return null;
}

async function resolveEntrySource(spec: string, baseDir: string): Promise<{ resolved: ResolvedEntrySource | null; status: "resolved" | "missing" | "partial" }> {
  const classified = EntryPredicate.classify(spec);
  if (classified?.form === "path") {
    const root = await PluginEntryResolver.packageRoot(spec, baseDir);
    if (root === null) return { resolved: null, status: "missing" };
    const copy = await readCopyManifest(root, "checkout");
    if (copy === null) return { resolved: null, status: "partial" };
    return { resolved: copy, status: "resolved" };
  }
  if (classified === null) return { resolved: null, status: "missing" };
  const keyDir = join(packageCacheRoot(), `${classified.name}@${classified.version}`);
  const copy = await findCacheCopy(keyDir, classified.name ?? spec);
  if (copy !== null) return { resolved: copy, status: "resolved" };
  return { resolved: null, status: (await exists(keyDir)) ? "partial" : "missing" };
}

async function findCacheCopy(keyDir: string, name: string): Promise<ResolvedEntrySource | null> {
  const direct = await readCopyManifest(keyDir, "cache");
  if (direct !== null) return direct;
  let entries;
  try {
    entries = await readdir(keyDir, { withFileTypes: true });
  } catch {
    return null;
  }
  let best: ResolvedEntrySource | null = null;
  for (const entry of entries) {
    if (!entry.isDirectory() || entry.name.startsWith(".")) continue;
    const copy = await readCopyManifest(join(keyDir, entry.name, "node_modules", name), "cache");
    if (copy === null) continue;
    if (best === null || (copy.modifiedMs ?? 0) > (best.modifiedMs ?? 0)) best = copy;
  }
  return best;
}

async function readCopyManifest(dir: string, source: "cache" | "checkout"): Promise<ResolvedEntrySource | null> {
  const manifestPath = join(dir, "package.json");
  if (!(await exists(manifestPath))) return null;
  try {
    const parsed = JSON.parse(await readFile(manifestPath, "utf-8")) as { name?: unknown; version?: unknown };
    const version = typeof parsed.version === "string" ? parsed.version : null;
    const name = typeof parsed.name === "string" ? parsed.name : null;
    const info = await stat(dir);
    return { version, name, source, path: dir, modifiedMs: info.mtimeMs };
  } catch {
    return null;
  }
}

function effectiveStatus(local: ScopeStatus | null, global: ScopeStatus | null): EffectiveStatus {
  const registeredScopes: Scope[] = [];
  if (local?.registered) registeredScopes.push("local");
  if (global?.registered) registeredScopes.push("global");
  for (const scopeStatusValue of [local, global]) {
    if (scopeStatusValue === null || !scopeStatusValue.registered) continue;
    if (scopeStatusValue.resolvedVersion !== null) {
      return {
        version: scopeStatusValue.resolvedVersion,
        versionKind: scopeStatusValue.resolvedSource,
        scope: scopeStatusValue.scope,
        latestVersion: scopeStatusValue.publishedVersion,
        registeredScopes,
      };
    }
    const fallback = specFallback(scopeStatusValue);
    if (fallback !== null) {
      return {
        version: fallback.version,
        versionKind: fallback.kind,
        scope: scopeStatusValue.scope,
        latestVersion: scopeStatusValue.publishedVersion,
        registeredScopes,
      };
    }
    return {
      version: scopeStatusValue.version,
      versionKind: scopeStatusValue.version !== null ? "manifest" : null,
      scope: scopeStatusValue.scope,
      latestVersion: scopeStatusValue.publishedVersion,
      registeredScopes,
    };
  }
  return { version: null, versionKind: null, scope: null, latestVersion: null, registeredScopes };
}

function specFallback(scopeStatusValue: ScopeStatus): { version: string; kind: "spec" | "npm" } | null {
  if (scopeStatusValue.entryVersion === null || scopeStatusValue.entryVersion === "latest") {
    if (scopeStatusValue.entryVersion === "latest" && scopeStatusValue.publishedVersion !== null) {
      return { version: scopeStatusValue.publishedVersion, kind: "npm" };
    }
    return null;
  }
  return isExactSemver(scopeStatusValue.entryVersion) ? { version: scopeStatusValue.entryVersion, kind: "spec" } : null;
}

function isExactSemver(version: string): boolean {
  return /^\d+\.\d+\.\d+(?:-[\w.-]+)?(?:\+[\w.-]+)?$/.test(version);
}

async function applyOnline(
  scopes: Array<ScopeStatus | null>,
  fetchFn: typeof fetch,
): Promise<{ warnings: string[]; scopes: Array<ScopeStatus | null> }> {
  const warnings: string[] = [];
  const lookups = new Map<string, { version: string | null; warning: string | null }>();
  const lookupName = (scopeStatusValue: ScopeStatus): string | null =>
    scopeStatusValue.entryName ?? scopeStatusValue.resolvedName;
  for (const scopeStatusValue of scopes) {
    if (scopeStatusValue === null || !scopeStatusValue.registered) continue;
    const name = lookupName(scopeStatusValue);
    if (name === null || lookups.has(name)) continue;
    lookups.set(name, await fetchLatestVersion(name, fetchFn));
  }
  const updated: Array<ScopeStatus | null> = [];
  for (const scopeStatusValue of scopes) {
    if (scopeStatusValue === null || !scopeStatusValue.registered) {
      updated.push(scopeStatusValue);
      continue;
    }
    const name = lookupName(scopeStatusValue);
    const lookup = name !== null ? lookups.get(name) : undefined;
    if (lookup === undefined) {
      updated.push(scopeStatusValue);
      continue;
    }
    if (lookup.warning !== null) {
      warnings.push(lookup.warning);
      updated.push({ ...scopeStatusValue, publishedVersion: null });
      continue;
    }
    if (lookup.version !== null && scopeStatusValue.resolvedVersion !== null && lookup.version !== scopeStatusValue.resolvedVersion) {
      warnings.push(`${lookup.version} is the latest published version but ${scopeStatusValue.resolvedVersion} resolves (stale)`);
    }
    updated.push({ ...scopeStatusValue, publishedVersion: lookup.version });
  }
  return { warnings, scopes: updated };
}

async function fetchLatestVersion(name: string, fetchFn: typeof fetch): Promise<{ version: string | null; warning: string | null }> {
  try {
    const response = await fetchFn(`https://registry.npmjs.org/${name}/latest`, { signal: AbortSignal.timeout(3000) });
    if (!response.ok) return { version: null, warning: `npm registry returned ${response.status} for ${name}` };
    const parsed = (await response.json()) as { version?: unknown };
    if (typeof parsed.version !== "string") return { version: null, warning: `npm registry response for ${name} carried no version` };
    return { version: parsed.version, warning: null };
  } catch (error) {
    const message = error instanceof Error ? error.message : String(error);
    return { version: null, warning: `could not query npm registry for ${name}: ${message}` };
  }
}

export async function isInstalledAnywhere(projectDir: string = process.cwd()): Promise<boolean> {
  const version = await getPackageVersion();
  for (const scope of ["global", "local"] as const) {
    const manifest = new InstallManifest(scopeBase(scope, projectDir), PLUGIN_NAME);
    const data = await manifest.read();
    if (data === null) continue;
    if (data.mode === "plugin" && data.entryConfigPath) {
      if ((await editor.findRegistration(PLUGIN_NAME, { scope, projectDir })) !== null) return true;
      continue;
    }
    if (data.version === version) return true;
  }
  return false;
}

function parseConfig(raw: string, path: string): unknown {
  return path.endsWith(".jsonc") ? parseJsonc(raw) : JSON.parse(raw);
}

async function readJsonConfig(path: string): Promise<Record<string, unknown> | null> {
  if (!(await exists(path))) return {};
  try {
    return parseConfig(await readFile(path, "utf-8"), path) as Record<string, unknown>;
  } catch {
    console.warn(`Warning: ${path} is not valid JSON; refusing to modify it.`);
    return null;
  }
}

async function writeJsonConfig(path: string, config: Record<string, unknown>): Promise<void> {
  await mkdir(join(path, ".."), { recursive: true });
  await writeFile(path, JSON.stringify(config, null, 2));
}
